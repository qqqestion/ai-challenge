
# День 32: God Agent

## Описание

Соедините все свои наработки в одного большого агента, который является вашим
личным сотрудником-помощником.

Агент принимает команды (текст/голос), понимает контекст, умеет пользоваться
инструментами/интеграциями проекта и выдает результат в одном понятном интерфейсе.

## Что нужно сделать

- Собрать единый «оркестратор» агента (одна точка входа), который управляет
  пайплайном: ввод → понимание → план/вызов инструментов → ответ.
- Подключить существующие модули проекта (LLM, память/история, инструменты/MCP,
  RAG/поиск, расписание/фоновая работа — если есть) в одну согласованную схему.
- Определить режимы работы (например: чат, голосовой режим, режим
  «помощник команды/проекта») и единые правила маршрутизации запросов.
- Сделать единый формат ответа (коротко/по делу, со ссылками на источники/действия,
  где применимо).
- Добавить минимальный e2e сценарий: 3–5 запросов, где агент использует разные
  возможности (память, инструмент, поиск по знаниям, планирование) и возвращает
  корректный итог.
